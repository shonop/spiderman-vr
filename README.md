# Spider-Man VR

משחק ספיידרמן ב-VR שבנוי על WebXR + Three.js + Vite. רץ בדפדפן של ה-Quest או על המחשב דרך Quest Link.

כשנכנסים למשחק מופיע תפריט שמרחף מעל גג (PLAY / SETTINGS). אחרי PLAY יורים קורים על בניינים ומתנדנדים בעיר שיש בה מכוניות, רמזורים ואנשים.

## הפעלה

הכי פשוט: לחיצה כפולה על `start-game.bat` (או על `Spider-Man VR server.bat` שעל שולחן העבודה). החלון מראה את הכתובת לפתוח בקווסט. השרת עובד רק כל עוד החלון פתוח.

או מהטרמינל:

```bash
npm install
npm run dev
```

השרת עולה ב-HTTPS על פורט 5173.

### בקווסט (Wi-Fi)
1. המחשב והקווסט צריכים להיות על אותה רשת.
2. בדפדפן של הקווסט פותחים את הכתובת `Network` שמופיעה בטרמינל, למשל `https://192.168.1.20:5173`.
3. מופיעה אזהרה על התעודה (זו תעודה מקומית לפיתוח) → Advanced → Proceed.
4. לוחצים **ENTER VR**.

### במחשב דרך Quest Link / Air Link
פותחים את `https://localhost:5173` ב-Chrome או ב-Edge, ומוודאים ש-Meta Horizon Link מוגדר כ-OpenXR runtime.

## שליטה

| פעולה | VR | מחשב |
|---|---|---|
| ירי קור (מחזיקים כדי להישאר תפוסים) | טריגר ביד ימין או שמאל | קליק ימני או שמאלי (או E / Q) |
| משיכה לכיוון הקור | Grip | Shift |
| הליכה / היגוי באוויר | סטיק שמאלי | WASD |
| סיבוב | סטיק ימני (קפיצות של 30°) | עכבר |
| קפיצה | A / X | Space |
| לחיצה בתפריט | טריגר | קליק |

לקורים יש טווח של 50 מטר (`WEB_RANGE` ב-`player.js`). כשהיד מכוונת לבניין בטווח מופיעה נקודה לבנה במקום שבו הקור ייתפס. בניין רחוק יותר מסומן בנקודה אדומה, והטריגר רק נותן רטט קצר בלי לירות. במחשב הכוונת מתמלאת באדום כשיש מטרה בטווח, ונהיית מקווקוות כשהבניין רחוק מדי.

## מבנה
- `src/main.js` – ה-renderer, מצבי המשחק (תפריט או משחק) והלולאה הראשית
- `src/menu.js` – התפריט התלת-ממדי: PLAY, SETTINGS (ריק כרגע) ו-BACK
- `src/input.js` – קריאת הבקרים, או המקלדת והעכבר במחשב
- `src/player.js` – הפיזיקה: כוח משיכה, הליכה, נחיתה על גגות, התנגשות בקירות ונדנוד על קורים
- `src/graphics.js` – שמיים, שמש, צללים וערפל, ותוספות לשיידרים (השתקפות של הזכוכית)
- `src/textures.js` – כל הטקסטורות (חזיתות, חנויות, אספלט, מדרכות) מצוירות בקוד על canvas
- `src/city.js` – העיר: בניינים עם חנויות בקומת הקרקע, גגות, הטיילת והמים שמסביב והקו של העיר ברקע
- `src/streets.js` – סימוני כביש ומעברי חצייה, פנסי רחוב, עצים, ברזי כיבוי ופחים
- `src/traffic.js` – מכוניות ורמזורים
- `src/people.js` – הולכי רגל עם ראש, שיער, ידיים ורגליים שזזות בהליכה
- `public/` – קבצים סטטיים (מודלים מסוג `.glb`, סאונדים, טקסטורות)

הקבועים בראש `player.js` (כמו `GRAVITY`, `REEL_SPEED`, `WEB_RANGE`) הם המקום לכוונן את התחושה של הנדנוד.

## Build
```bash
npm run build
```
התוצאה נכנסת ל-`dist/` ואפשר להעלות אותה לכל אחסון סטטי עם HTTPS.
