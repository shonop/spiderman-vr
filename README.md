# Spider-Man VR

משחק ספיידרמן ב-VR שבנוי על WebXR + Three.js + Vite. רץ בדפדפן של ה-Quest או על המחשב דרך Quest Link.

כשנכנסים למשחק מופיע תפריט שמרחף מעל גג (PLAY / SETTINGS). אחרי PLAY יורים קורים על בניינים ומתנדנדים בעיר שיש בה מכוניות, רמזורים ואנשים.

## ידיים
במקום הבקרים רואים ידיים אמיתיות של אדם (עם השרוול ומכשיר ה-web shooter על פרק כף היד), והן זזות לפי מה שהאצבעות עושות על הבקר:
- Grip סוגר את האגודל, האמה והקמיצה לאגרוף. משחררים והיד נפתחת.
- אצבע על הטריגר בלי ללחוץ: האצבע מתכופפת. מורידים אותה מהטריגר: האצבע מצביעה.
- אגודל על הכפתורים או על הסטיק: האגודל מונח. מרימים אותו: אגודל למעלה.
- לחיצה על הטריגר: תנועת ה-"thwip" של ספיידרמן (אמה וקמיצה למטה, האצבע והזרת ישרות), והקור יוצא מהנחיר שעל פרק היד עם ענן לבן קטן.

במחשב רואים את שתי הידיים בתחתית המסך, ו-F מוציא אגרוף (פעם יד ימין ופעם שמאל).
התנוחות נמצאות ב-`POSES` בראש `hands.js`, והמיקום של היד ביחס לבקר ב-`GRIP_OFFSET`.

## אויבים
30 שניות אחרי PLAY מופיעה כנופיה של בריונים בפינת רחוב. כל אחד נראה אחרת (קפוצ'ון, כובע גרב, בנדנה, זקן, גוון עור), , 100–200 מטר מהשחקן. עמוד אור אדום מעליהם נראה מכל העיר, וחץ צהוב מול השחקן מצביע אליהם. בחלק העליון של המבט מופיעים כמה בריונים נשארו, המרחק אליהם ופס החיים.

- הם מחכים עד שיורדים לרחוב לידם (25 מטר), ואז רצים אליך, מרימים ידיים לעמידת קרב ומתקרבים בצעדים קטנים. על גג או על קור הם לא יכולים להגיע אליך, אז הם רק בוהים בך.
- הם מרביצים במכות אמיתיות: ג'אב, קרוס (לפעמים קומבינציה של שניהם), הוק, אפרקאט ובעיטה. כל מכה מכוונת לראש שלך. אפשר להתחמק אם זזים בזמן, וב-VR אפשר לחסום עם יד מול הפנים.
- כשמכים אותם הראש נזרק הצידה (או שהם מתקפלים ממכה בבטן), ובמכת נוקאאוט הברכיים מתקפלות והם נופלים על הגב.
- ב-VR מרביצים להם עם תנועת אגרוף אמיתית של הבקר. ככל שהמכה מהירה יותר היא חזקה יותר. במחשב: F או קליק אמצעי.
- כשהם פוגעים בך המסך מאדים והבקרים רוטטים. החיים חוזרים לאט אחרי 5 שניות בלי מכות. אם החיים נגמרים חוזרים לגג ההתחלה והכנופיה מתאוששת.
- כשכולם מנוקים מופיע AREA CLEAR!, ואחרי 30 שניות מגיע גל חדש עם יותר בריונים (עד 6).

הקבועים בראש `enemies.js` (`FIRST_WAVE_DELAY`, `REACH`, `PUNCH_SPEED` ועוד), והנזק והתזמון של כל מכה ב-`MOVES` שב-`brawl.js`, הם המקום לכוונן את הקושי.

## הפעלה

הכי פשוט: לחיצה כפולה על `start-game.bat` (או על `Spider-Man VR server.bat` שעל שולחן העבודה). החלון מראה את הכתובת לפתוח בקווסט. השרת עובד רק כל עוד החלון פתוח.

או מהטרמינל:

```bash
npm install
npm run dev
```

השרת עולה ב-HTTPS על פורט 5173.

### בקווסט (Wi-Fi)
1. המחשב והקווסט צריכים להיות על אותה רשת.
2. בדפדפן של הקווסט פותחים את הכתובת `Network` שמופיעה בטרמינל, למשל `https://192.168.1.20:5173`.
3. מופיעה אזהרה על התעודה (זו תעודה מקומית לפיתוח) → Advanced → Proceed.
4. לוחצים **ENTER VR**.

### במחשב דרך Quest Link / Air Link
פותחים את `https://localhost:5173` ב-Chrome או ב-Edge, ומוודאים ש-Meta Horizon Link מוגדר כ-OpenXR runtime.

## שליטה

| פעולה | VR | מחשב |
|---|---|---|
| ירי קור (מחזיקים כדי להישאר תפוסים) | טריגר ביד ימין או שמאל | קליק ימני או שמאלי (או E / Q) |
| משיכה לכיוון הקור | Grip | Shift |
| הליכה / היגוי באוויר | סטיק שמאלי | WASD |
| סיבוב הראש | סטיק ימני (סיבוב חלק סביב הראש, `TURN_SPEED` ב-`input.js`) | עכבר |
| קפיצה | A / X | Space |
| אגרוף | לסגור אגרוף (Grip) ולהניף את היד | F או קליק אמצעי |
| לחיצה בתפריט | טריגר | קליק |

לקורים יש טווח של 50 מטר (`WEB_RANGE` ב-`player.js`). כשהיד מכוונת לבניין בטווח מופיעה נקודה לבנה במקום שבו הקור ייתפס. בניין רחוק יותר מסומן בנקודה אדומה, והטריגר רק נותן רטט קצר בלי לירות. במחשב הכוונת מתמלאת באדום כשיש מטרה בטווח, ונהיית מקווקוות כשהבניין רחוק מדי.

## מבנה
- `src/main.js` – ה-renderer, מצבי המשחק (תפריט או משחק) והלולאה הראשית
- `src/menu.js` – התפריט התלת-ממדי: PLAY, SETTINGS (ריק כרגע) ו-BACK
- `src/input.js` – קריאת הבקרים, או המקלדת והעכבר במחשב
- `src/hands.js` – הידיים בגוף ראשון: מודל עם שלד, התנוחות של האצבעות, ה-web shooter והאגרוף במחשב
- `src/player.js` – הפיזיקה: כוח משיכה, הליכה, נחיתה על גגות, התנגשות בקירות ונדנוד על קורים
- `src/graphics.js` – שמיים, שמש, צללים וערפל, ותוספות לשיידרים (השתקפות של הזכוכית)
- `src/textures.js` – כל הטקסטורות (חזיתות, חנויות, אספלט, מדרכות) מצוירות בקוד על canvas
- `src/city.js` – העיר: בניינים עם חנויות בקומת הקרקע, גגות, הטיילת והמים שמסביב והקו של העיר ברקע
- `src/streets.js` – סימוני כביש ומעברי חצייה, פנסי רחוב, עצים, ברזי כיבוי ופחים
- `src/traffic.js` – מכוניות ורמזורים
- `src/human.js` – גוף אדם מפורט עם שלד (פנים, אוזניים, אצבעות, בגדים עם קפלים ותפרים), תנוחות והליכה
- `src/brawl.js` – אנימציות הקרב: עמידת קרב, המכות, ספיגת מכה ונפילה בנוקאאוט
- `src/people.js` – הולכי רגל. עשרת הקרובים לשחקן מקבלים גוף מפורט, והרחוקים דמות פשוטה וזולה
- `src/enemies.js` – הבריונים: גלים, בינה מלאכותית, אגרופים לשני הכיוונים, החיים של השחקן, עמוד הסימון והחץ
- `src/status.js` – הפאנל הקטן מול העיניים (הודעות, משימה, חיים) והאדמה של המסך כשנפגעים
- `src/sound.js` – אפקטי סאונד של מכות, מסונתזים בקוד בלי קבצים
- `public/` – קבצים סטטיים: האייקונים של האפליקציה, `manifest.webmanifest` ו-`sw.js` (פתיחה בלי אינטרנט)

הקבועים בראש `player.js` (כמו `GRAVITY`, `REEL_SPEED`, `WEB_RANGE`) הם המקום לכוונן את התחושה של הנדנוד.

## Build
```bash
npm run build
```
התוצאה נכנסת ל-`dist/` ואפשר להעלות אותה לכל אחסון סטטי עם HTTPS (הנתיבים יחסיים, אז זה עובד גם בתוך תיקייה כמו GitHub Pages).

## התקנה כאפליקציה בקווסט
המשחק הוא PWA: יש לו שם, אייקון, מסך מלא ו-service worker שמאפשר לפתוח אותו גם בלי אינטרנט. כדי שהקווסט יציע להתקין אותו הוא צריך לעלות לכתובת HTTPS אמיתית (לא לשרת המקומי עם האזהרה על התעודה):
1. `npm run build` ומעלים את `dist/` לאחסון סטטי (GitHub Pages, Netlify, Cloudflare Pages).
2. בדפדפן של הקווסט פותחים את הכתובת, ובתפריט של הדפדפן בוחרים **Install** / **Add to library**.
3. המשחק מופיע בספרייה של הקווסט עם האייקון ונפתח כמו כל אפליקציה.

כדי להפוך אותו ל-APK אמיתי (למשל להעלאה לחנות של Meta) אפשר לעטוף את אותה כתובת עם Bubblewrap.
